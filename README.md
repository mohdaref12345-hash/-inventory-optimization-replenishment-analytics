# Inventory Optimization & Replenishment Analytics

A two-page Power BI portfolio project focused on inventory analytics and replenishment review.

## Report pages
- **Inventory Analytics:** demand trend, category demand, inventory value, average reorder point, average safety stock, and ABC product distribution.
- **Replenishment Analysis:** products below reorder point, stock status, and recommended order quantity by category.

## Tools
Power BI · DAX · Microsoft Excel

## View
Open `index.html` locally, or publish this folder using GitHub Pages. The `.pbix` report is available for download and requires Power BI Desktop to explore interactively.

## Note
The report includes 40 SKU records. Recommended order quantity is the replenishment quantity represented in this report; it should not be interpreted as a fully optimized procurement model.

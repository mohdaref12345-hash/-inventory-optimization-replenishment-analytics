# Inventory Optimization & Replenishment Analytics
### Power BI | Inventory Management | Demand Analysis | Replenishment Planning

## Project Overview

This project analyzes inventory levels, product demand, and replenishment requirements using Microsoft Power BI.

The objective is to support inventory management decisions by identifying products that may require replenishment, analyzing demand patterns, and presenting inventory insights through interactive dashboards.

The report contains two dashboard pages focused on inventory analytics and replenishment planning.

## Project Objectives

- Analyze product demand and inventory levels.
- Identify products that may require replenishment.
- Monitor inventory performance using key performance indicators (KPIs).
- Explore demand patterns across product categories and time periods.
- Support inventory planning through interactive visualizations.

## Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Microsoft Excel** — Data management
- **DAX** — Measures and KPI calculations
- **CSV and Excel files** — Data sources

## Dashboard Overview

### Page 1 — Inventory Analytics Dashboard

Provides an overview of inventory performance and demand patterns.

Features include:
- Product details and inventory information
- Demand by category
- Daily demand trend
- Average reorder point by category
- Average safety stock by category
- Product distribution by ABC classification
- KPI cards for overall performance

### Page 2 — Replenishment Dashboard

Focuses on stock availability and replenishment requirements.

Features include:
- Inventory stock status
- Products requiring replenishment
- Recommended replenishment quantities
- Product-level replenishment analysis

## Key Performance Indicators

| KPI | Description |
|---|---|
| Total Sales | Total sales value represented in the report |
| Total Demand | Total demand recorded in the dataset |
| Average Lead Time | Average replenishment lead time |
| Recommended Order Quantity | Replenishment quantity represented in the report |
| Inventory Value | Estimated inventory value |

## Project Scope & Limitations

The recommended order quantity represents the replenishment quantity calculated and displayed in the current report.

This project focuses on inventory analytics and replenishment reporting. It should not be interpreted as a fully optimized procurement model or an automated inventory management system. Results depend on the underlying dataset and the calculations used.
